GenLayer Asimov

Launch a token that carries a rule, and operate it.

This deploys the project's GenLayer rule contract, contracts/token.py, fetched straight from the repository so the code you run is the code you can read. The token is launched with a plain-language rule, a treasury and a bounty, and then anyone can fund it and fire the rule. When the rule's condition is true, a validator round burns from the treasury.
